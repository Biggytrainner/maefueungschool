# ระบบการลาและสอนแทน โรงเรียนบ้านแม่เฟือง · สพป.ลำปาง เขต 1

ระบบแจ้งลา ออกใบลา อนุมัติ และมอบหมายครูสอนแทน ใช้ **GitHub + Netlify เท่านั้น** ไม่ต้องใช้ Firebase
ข้อมูลเก็บกลางที่ Netlify Blobs ผ่าน Netlify Function ทุกเครื่องที่เปิดเว็บเดียวกันจึงเห็นและแก้ข้อมูลชุดเดียวกัน (อัปเดตอัตโนมัติทุก ~15 วินาที และทันทีเมื่อกลับมาที่แท็บ)

## ความสามารถ
- ครูแจ้งลา เลือกครูสอนแทนรายคาบ พิมพ์ใบลา / บันทึกเป็น PDF
- ใบลาป่วย / ลากิจส่วนตัว / ลาคลอดบุตร พิมพ์ตามแบบมาตรฐานของโรงเรียน (A4 หน้าเดียว) ดึงข้อมูลการลาครั้งสุดท้ายและสถิติปีงบประมาณมากรอกให้อัตโนมัติ
- หน้า "ข้อมูลของฉัน" สรุปการลาตามปีงบประมาณ (ทั้งหมด/อนุมัติ/รออนุมัติ/ไม่อนุมัติ/ยกเลิก/รอรับทราบ) กดดูรายละเอียด พิมพ์ย้อนหลัง ดาวน์โหลดใบลา และยกเลิกใบลาได้
- ผู้อำนวยการอนุมัติหรือไม่อนุมัติใบลา
- ส่วนหัวทักทายผู้ใช้ที่เข้าสู่ระบบ แสดงวันที่ เวลา (เดินตามจริงทุกวินาที) และปีการศึกษา เช่น ปีการศึกษา 2570 (1 ตุลาคม 2569 – 30 กันยายน 2570) คำนวณจากวันที่ปัจจุบันของเครื่อง
- การลบใบลาต้องกรอก PIN ของผู้ลบเพื่อยืนยันทุกครั้ง (ผู้ดูแลระบบใช้รหัสผ่านผู้ดูแล) กรอกผิดครบ 5 ครั้งระบบจะยกเลิกการลบ
- แท็บ “ปฏิทินการลา” (เฉพาะผู้อำนวยการ) แสดงการลาของครูทุกคนเป็นรายเดือน แยกสีใบลาที่อนุมัติแล้ว/รออนุมัติ กดวันที่เพื่อดูรายชื่อและเปิดรายละเอียดใบลา
- ครูที่ได้รับมอบหมายกด "รับทราบงาน"
- นำชื่อครูเข้า/ออก (ถามยืนยันทุกครั้ง)
- ผู้ดูแลระบบ (มีคนเดียว) กำหนดสิทธิ์ ครู / ผู้อำนวยการ / ฝ่ายบุคคล และรีเซ็ต PIN

ผู้ดูแลระบบเริ่มต้น: `Admin` / `1234` **ควรเปลี่ยนก่อนใช้งานจริง** (ตัวแปร `ADMIN_USER`, `ADMIN_PASS` ใน `public/index.html`)

## วิธีติดตั้ง
1. สร้าง repository บน GitHub แล้วอัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ (ต้องมี `netlify/`, `public/`, `package.json`, `netlify.toml`)
2. เข้า https://app.netlify.com → **Add new site → Import an existing project → GitHub** เลือก repository นี้
3. ตั้งค่า Build: ปล่อย **Build command ว่าง** (Publish directory และ Functions อ่านจาก `netlify.toml` ให้เอง) แล้วกด **Deploy**
4. เปิดลิงก์ `https://<ชื่อไซต์>.netlify.app` จากหลายเครื่องเพื่อทดสอบ ถ้าสำเร็จ มุมบนจะขึ้น **"ข้อมูลใช้ร่วมกัน"**
5. เมื่อแก้ไฟล์แล้ว push ขึ้น GitHub Netlify จะ deploy ให้อัตโนมัติ (ข้อมูลในฐานข้อมูลไม่หาย)

> GitHub Pages อย่างเดียวใช้ฐานข้อมูลกลางไม่ได้ เพราะไม่มีฝั่งเซิร์ฟเวอร์ ถ้าเปิดไฟล์โดยไม่มี Netlify ระบบจะเก็บข้อมูลไว้ในเบราว์เซอร์เครื่องนั้นเท่านั้น

## ข้อจำกัดที่ควรรู้
- **ความปลอดภัย:** ทุกคนที่รู้ลิงก์เว็บเรียกอ่าน/เขียน `/api` ได้ การแบ่งสิทธิ์ทำในหน้าเว็บ เหมาะกับใช้ภายในโรงเรียน อย่าแชร์ลิงก์สาธารณะ และห้ามเก็บข้อมูลที่อ่อนไหวมาก ตั้งชื่อไซต์ใน Netlify ให้เดายาก (Site settings → Change site name)
- **รหัสผ่านแอดมินอยู่ในซอร์สโค้ด** ถ้า repository เป็นสาธารณะ ใครก็เห็น ควรใช้ Private repository
- **เขียนพร้อมกัน:** ข้อมูลทั้งหมดเก็บในไฟล์เดียว หากสองคนกดบันทึกพร้อมกันในเสี้ยววินาที อาจมีรายการหนึ่งถูกทับได้ (เกิดน้อยมากกับโรงเรียนขนาดนี้)
- **โควตา Netlify:** ทุกเครื่องที่เปิดหน้าเว็บค้างไว้จะเรียก `/api` ทุก ~15 วินาที (เฉพาะตอนแท็บแสดงอยู่) ตรวจโควตาแผนฟรีของ Netlify ให้เพียงพอกับจำนวนผู้ใช้
- **รหัส PIN ของผู้ใช้** เก็บเป็นค่าแฮชในฐานข้อมูล ไม่ใช่ข้อความจริง

## ฟอนต์ใบลา (TH Sarabun PSK)
ใบลาใช้ฟอนต์ **TH Sarabun PSK** ถ้าเครื่องติดตั้งฟอนต์นี้ไว้ (ส่วนใหญ่เครื่องหน่วยงานราชการมีอยู่แล้ว) จะใช้ได้ทันที
หากต้องการให้แสดงตรงกันทุกเครื่องรวมถึงมือถือ ให้วางไฟล์ `THSarabunPSK.ttf` และ `THSarabunPSK-Bold.ttf` ลงในโฟลเดอร์ `public/fonts/` แล้ว push ขึ้น GitHub (ดาวน์โหลดฟอนต์ได้จากเว็บไซต์ SIPA ผู้เผยแพร่ฟอนต์ภาษาไทยฟรี) ถ้าไม่มีทั้งสองกรณี ระบบจะใช้ฟอนต์สำรองคือ Sarabun
