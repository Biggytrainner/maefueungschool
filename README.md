# ระบบการลาและสอนแทน โรงเรียนบ้านแม่เฟือง · สพป.ลำปาง เขต 1

ระบบแจ้งลา ออกใบลา อนุมัติ และมอบหมายครูสอนแทน เป็นไฟล์ HTML ไฟล์เดียว ไม่ต้องติดตั้งอะไรเพิ่ม

## ความสามารถ
- ครูแจ้งลาและเลือกครูสอนแทนรายคาบ พิมพ์ใบลา / บันทึกเป็น PDF
- ผู้อำนวยการอนุมัติหรือไม่อนุมัติใบลา
- ครูที่ได้รับมอบหมายกด "รับทราบงาน"
- นำชื่อครูสอนแทนเข้า/ออกได้ (ถามยืนยันทุกครั้ง)
- ผู้ดูแลระบบกำหนดสิทธิ์ผู้ใช้ (ครู / ผู้อำนวยการ / ฝ่ายบุคคล) และรีเซ็ต PIN
- ธีมส้มครีม สไตล์กระจกใส รองรับโหมดมืด

## สิทธิ์ผู้ใช้
| สิทธิ์ | ทำได้ |
|---|---|
| ครู | แจ้งลา ดูรายการ รับทราบงานสอนแทน เปลี่ยน PIN |
| ผู้อำนวยการ | อนุมัติใบลา + สิทธิ์ของครู |
| ฝ่ายบุคคล | ดูทุกรายการ ส่งออก CSV รีเซ็ต PIN |
| ผู้ดูแลระบบ (มีคนเดียว) | กำหนดสิทธิ์ เพิ่ม/นำชื่อออก รีเซ็ต PIN |

ผู้ดูแลระบบเริ่มต้น: ชื่อผู้ใช้ `Admin` รหัสผ่าน `1234`
**ควรเปลี่ยนก่อนใช้งานจริง** โดยแก้ตัวแปร `ADMIN_USER` และ `ADMIN_PASS` ใน `index.html`

## เผยแพร่ด้วย GitHub Pages
1. สร้าง repository ใหม่บน GitHub แล้วอัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้
2. ไปที่ Settings → Pages
3. Source เลือก `Deploy from a branch` → Branch `main` / โฟลเดอร์ `/ (root)` → Save
4. รอสักครู่ จะได้ลิงก์ `https://<ชื่อผู้ใช้>.github.io/<ชื่อ repo>/`

## ข้อควรรู้เรื่องข้อมูล
- เมื่อเปิดนอกแพลตฟอร์ม Claude ระบบจะเก็บข้อมูลใน **เบราว์เซอร์ของแต่ละเครื่อง** (localStorage) ข้อมูลจึงไม่ถูกแชร์ระหว่างเครื่อง
- ถ้าต้องการให้ครูทุกคนใช้ข้อมูลร่วมกัน ต้องต่อฐานข้อมูลกลาง (เช่น Firebase Firestore) เพิ่ม
- รหัสผ่านผู้ดูแลระบบอยู่ในซอร์สโค้ด ใครเปิดดูโค้ดก็เห็น อย่าใช้ปกป้องข้อมูลสำคัญ
- อย่าเก็บข้อมูลส่วนบุคคลจริงใน repository สาธารณะ
